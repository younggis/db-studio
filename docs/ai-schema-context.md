# Schema Context

更新日期：2026-11-17

## 读取范围

请求只有在面板开启“允许将本次匹配的表结构发送给模型”后才读取 Schema。当前连接决定数据库、服务端版本和方言；默认选择当前 Schema，用户最多可显式选择 16 个 Schema 和相关表。候选表只从选中的 Schema 中读取。上下文最多 8 张表、每张 160 列和 40 条外键，表与空间 Schema 元数据 JSON 合计最多 48,000 个字符；达到总量上限时按表轮流保留列和关系，并在助手响应中显示截断警告。元数据缓存按连接/Schema/表隔离，有效 5 分钟，可在请求中刷新。

字段包含名称、数据库类型、可空、主键和可用备注；关系包含外键列到引用列映射。PostgreSQL 可读取表/列备注。SQL 辅助不读取表行。

## PostgreSQL/PostGIS

GIS 助手要求 PostgreSQL、启用 Schema 同意、只选一个 Schema 并明确选择空间表。Main 读取 PostGIS 版本、`geometry_columns` / `geography_columns`、几何类型、SRID、坐标维数及有限的已安装函数签名。生成结果按 PostGIS 方言提示距离单位和 SRID 注意事项，只返回只读草稿。

## 相关表检索

无本机向量索引时，按关键词检索候选；启用 Embedding 后，按每个已选 Schema 独立匹配兼容索引，再合并关键词和余弦语义分数。索引缺失或格式不兼容时显示警告，并继续使用关键词或其他兼容范围。启用且配置了 Rerank 后，仅对最多 12 个本地召回候选做二次排序，最后选取最多 8 张表。显式选中的表优先。召回不到的表不会被 Rerank 找回。

完整索引格式、加密和模型切换规则见[Embedding/RAG](ai-embedding-rag.md)。
