# AI SQL 安全边界

更新日期：2026-11-14

## 密钥与网络

桌面密钥只由 Electron Main 读取并以 DPAPI / `safeStorage` 加密保存；Renderer 只获得密钥是否存在的标记。CLI 从进程环境读取。Provider 不接受带凭据、查询参数或片段的 URL，拒绝远程 HTTP、私网 DNS 解析和重定向。错误响应会遮蔽 Bearer/API Key。

## 数据出站

默认不读取或发送 Schema。用户须对每次助手请求明确开启 Schema 同意；Embedding 索引还需要用户明确选表并点击建立。仅发送有上限的 Schema 元数据，不读取业务行；SQL 助手每次请求中的表和空间 Schema JSON 合计最多 48,000 个字符，超限会截断并返回明确警告。Rerank 也位于同一 Schema 同意分支中，最多接收 12 个被截断的 Schema 文档及截断后的 Query。取消和窗口销毁会终止或丢弃未完成请求。

## SQL 边界

AI 没有数据库执行接口。生成、修复和 PostGIS 任务只允许单条只读 `SELECT` / `WITH` 候选；`node-sql-parser` 静态检查引用对象、方言和明显写操作，多语句、写入和已识别危险函数会被拒绝或提示。输出必须经过用户预览、用户确认才可插入或替换编辑器文本。

静态解析不是数据库权限控制，不能证明查询语法或运行成本安全。Oracle 当前使用更保守的风险检查；对未知扩展、动态 SQL 和模型幻觉仍须人工审查。优化建议没有真实计划时不能声称性能一定改善。

## 测试数据

2026-11-02 的真实云端冒烟使用进程环境里的 Key 和合成 Schema；测试输出不含密钥、生成 SQL 或 Schema 内容。没有向模型发送 `F:\GeoData` / `F:\temp` 数据、数据库业务行或真实连接信息。

2026-11-03 增加了回归测试：给 SQL 助手传入带恶意指令的 Schema 注释，以及额外的伪造数据库密码、连接 URI 和业务行字段；发送给模型的上下文仅含 Schema 白名单字段，系统消息明确将 Schema 元数据视为不可信输入。测试模型即使返回 `DELETE`，只读 SQL 验证仍会拒绝该结果。Chat、Embedding、Rerank 的最新最小连通测试均通过；它们没有收到项目 Schema 或本地数据。

2026-11-14 的 Task 12.4 回归再次验证了上述注释注入和上下文白名单行为；AI 单测 63/63、桌面单测 64/64 通过。桌面界面只把结果作为预览保存；仅由用户点击“插入编辑器”或“接受并应用修复”调用编辑器变更回调。旧请求在连接作用域变化后会被取消或丢弃。AI 尚未启用时，助手请求不可运行，现有 SQL 编辑器仍独立工作；本轮这些 UI 行为按源码与单测核对，没有完成安装版窗口逐项点击验收。

## 数据库权限边界

应用层不把模型候选交给数据库执行；实际 SQL 仍由用户通过现有连接手动运行。数据库账号权限是独立的第二道边界：若需要只读查询，应使用目标数据库授予只读权限的连接账号，不能把静态 SQL 验证当作权限控制。

2026-11-14 发现原项目 PostGIS 自动化账号 `dbstudio` 是超级用户。PostgreSQL、MySQL 8.4、MariaDB 11.4、SQL Server 2022、Oracle Free 和 MongoDB 7 均已通过项目隔离服务的最小权限集成检查：关系型账号只获一张合成表的 `SELECT`，MongoDB 角色只获一张合成集合的 `find`；未授权读取与写入/DDL 被数据库拒绝，哨兵不变，临时账号和夹具清理验证通过。SQLite 新增 `SqliteConnectionConfig.readOnly` 文件只读打开方式；独立临时数据库验证 `SELECT` 成功、DML/DDL 被 SQLite 拒绝，文件已删除。SQLite 只读权限覆盖整个文件，不支持单表权限。该结果证明隔离测试引擎执行了对应权限约束；它不意味着现有连接或业务账号已自动变为只读。

当前 44CA Windows 安装包的 REA fuse 读取（Evidence `ev_b1dd8987f90b0079bd531f27cb31d6e6f2059d09207caa32e99ede0c8a6fc540`）观察到 RunAsNode、NodeOptions、Inspector 参数和额外 File Protocol 权限启用，ASAR 完整性验证与仅从 app.asar 加载关闭。隔离启动以 `0x80000003` 退出，根因尚未确定。新 hardened MSI 已关闭未用 Node 注入/调试入口并启用 ASAR 检查，REA 静态复核与构建通过，但待针对新包即时授权安装和启动回归；静态 fuse 变化不证明它能修复启动异常。


### 请求过程中的同意状态（2026-11-14）

Chat 或 Schema Embedding 请求运行期间，Schema 同意复选框保持禁用，避免界面显示成已撤回但进行中请求仍按原授权范围处理。用户可取消未完成请求；已传输到 Provider 的内容不能通过本地取消操作撤回。
